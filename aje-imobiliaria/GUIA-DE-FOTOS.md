# Guía de fotos — Ajé Imobiliária

Todas las carpetas están dentro de: `aje-imobiliaria/public/images/`

**Cómo funciona:** mientras la carpeta no tenga el archivo, el sitio muestra
automáticamente una foto bonita de banco gratuito como reemplazo. Apenas
arrastres tu foto real con el **nombre exacto** (tal cual aparece abajo,
incluyendo mayúsculas/minúsculas y guiones), el sitio la usa a ella. No hay
que tocar código ni avisarme — solo recargar la página para verla.

### Tips rápidos
- El formato puede ser `.jpg`, `.jpeg` o `.png` — pero si usas otra extensión, dímelo para ajustar el nombre en el código.
- No hace falta que sean perfectas en tamaño — el sitio las recorta automáticamente para que se vean bien.
- Si subes una foto y no aparece, revisa que el nombre esté escrito EXACTAMENTE igual (sin espacios, minúsculas, mismos guiones).
